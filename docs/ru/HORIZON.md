# Horizon (P5) — отложенный roadmap

[English](../HORIZON.md)

Эти пункты **намеренно не реализованы**, пока P0–P4 не стабильны в проде.
Это продуктовые опции, а не ближайшие инженерные задачи.

## P5.1 — C++ растеризатор внутри OBS (без кадров Electron CEF)

Заменить offscreen Chromium → SHM/TCP-текстуры на композитор в плагине, который рисует
слои по компактному протоколу сцены. Месяцы C++/графики; риск расхождения editor↔OBS.
**Делать после** того, как путь shared-memory (P1b) исчерпан и профилирование показывает жёсткий потолок.

## P5.2 — Переписывание UI-фреймворка (React / Qt / …)

Vue 3 + Fluent shell уже в проде (M7). Переписывание — квартал+ заморозки фич.
Лучше унифицировать CSS `fluent-panel-*` и покрытие EmptyState.

## P5.3 — Нативное мобильное приложение

Удалённые моды уже работают через браузер + connector. Сначала сделайте **Perform mode**
как адаптивный web/PWA; только потом Capacitor / store — тонкая оболочка, не полный
порт EditorView.

См. также план улучшений проекта (Cursor plans), фаза P5.
