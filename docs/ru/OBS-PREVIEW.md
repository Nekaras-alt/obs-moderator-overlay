# Превью OBS (MJPEG + опциональный WHEP)

[English](../OBS-PREVIEW.md)

Модераторы могут открыть **Панели → OBS Preview**, чтобы смотреть текущий Program
(или цель Preview) внутри редактора.

## По умолчанию: MJPEG-скриншоты

Без дополнительного ПО. Пока открыто окно превью, сервер запрашивает у OBS
JPEG-кадры через `GetSourceScreenshot` (~4 FPS, ширина 960).

| Env | По умолчанию | Смысл |
|-----|--------------|--------|
| `OBS_PREVIEW_FPS` | `4` | Кадров в секунду (1–10) |
| `OBS_PREVIEW_WIDTH` | `960` | Макс. ширина |
| `OBS_PREVIEW_QUALITY` | `40` | Качество JPEG |

Цикл **останавливается**, когда превью никто не смотрит (экономия CPU).

OBS WebSocket остаётся на `127.0.0.1:4455`. Модераторы ходят только к приложению
на порту Tailscale **8090**.

## Быстрый путь: MediaMTX + OBS WHIP (опционально)

Для меньшей задержки запустите [MediaMTX](https://github.com/bluenviron/mediamtx) на
ПК стримера и направьте OBS **WHIP Output** туда. Затем:

```env
OBS_PREVIEW_WHEP_URL=http://127.0.0.1:8889/obs-preview/whep
```

### Пример фрагмента MediaMTX

```yml
paths:
  obs-preview:
    source: publisher
```

1. Запустите MediaMTX на машине стримера.
2. В OBS: WHIP Output → `http://127.0.0.1:8889/obs-preview/whip` (точный путь — в доках MediaMTX).
3. Укажите `OBS_PREVIEW_WHEP_URL` на соответствующий WHEP URL.
4. Перезапустите сервер оверлея. Превью предпочитает WHEP; при сбое — откат на MJPEG.

### Заметка про Tailscale

Если модераторы не достучатся до `127.0.0.1` на ПК стримера:

- позже проксировать WHEP через приложение, или
- подставить Tailscale IP стримера в `OBS_PREVIEW_WHEP_URL` и открыть порт в ACL Tailscale (кроме 8090). Лучше держать ACL минимальным — MJPEG на 8090 лишних портов не требует.

## Границы layout

**Вид → Границы OBS** рисует на холсте живые прямоугольники источников (поворот,
имена, группы). Они обновляются из событий obs-websocket и **не** попадают в
Browser Source оверлея для зрителей.
