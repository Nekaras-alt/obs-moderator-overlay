# Руководство пользователя (1.0)

[English](../USER.md)

## Роли

| Кто | Режим приложения | Что делает |
|-----|------------------|------------|
| Стример (классика) | **host** по умолчанию | Сервер на ПК с OBS, создаёт PIN, плагин Native или Browser (local) |
| Стример (только плагин) | — | OBS + плагин OMO **Browser (remote)**; вставляет URL оверлея от модератора |
| Модератор (host для «только плагин») | **host** по умолчанию | Запускает программу; сцена и медиа живут здесь; копирует URL оверлея стримеру |
| Модератор (локально) | тот же URL host | Вводит PIN, правит оверлей |
| Модератор (удалённый редактор) | `--mode=remote` | Join code → затем PIN (классика: host на ПК стримера) |
| Только sidecar OBS | `--mode=host-obs` | Трей + кадры оверлея, без окна редактора |

## Первый PIN

При **первом** запуске (пустой профиль) PIN нет, пока стример не введёт его (и не подтвердит). Токены для OBS Browser Source создаются автоматически.

После PIN короткий **тур** показывает Слои, холст, Inspector и остальное. Можно пропустить. Справочник — кнопка **?** в верхней панели (`Ctrl+Shift+/`). Тур можно запустить снова из справочника.

- Делитесь PIN только с доверенными модами.
- Смена: **Настройки → Безопасность** без удаления `data/.secret`.
- Удаление `data/.secret` сбрасывает настройку (новый viewer token → обновите URL в OBS).

В установленных Windows-сборках PIN хранится в профиле Electron (сохраняется при **переустановке** Setup.exe, если не удалять данные приложения):

- `%APPDATA%\obs-moderator-overlay\`
- или `%APPDATA%\OBS Moderator Overlay\`

«Установка для всех пользователей» меняет только каталог в Program Files — PIN всё равно **на пользователя Windows** в AppData.

Чтобы снова увидеть экран создания PIN:

1. Полностью закройте приложение (и трей).
2. Удалите OBS Moderator Overlay (новые сборки чистят AppData) **или** удалите папку AppData выше.
3. Запустите снова.

**Не** кладите настоящий `.secret` в `build/portable-seed` и публичные zip.

## Плагин OBS OMO Connector

Отдельный установщик: **OBS-OMO-Connector-Plugin-Setup-*.exe** из [Releases](../../releases) (нужны права администратора).

Плагин ставится в каталог OBS:

- `C:\Program Files\obs-studio\obs-plugins\64bit\omo-connector.dll`
- `C:\Program Files\obs-studio\data\obs-plugins\omo-connector\locale\`

Также чекбокс в основном Setup приложения ставит туда же (не в `%AppData%` — OBS оттуда плагин не подхватывает).

Перезапустите OBS → источник **OMO Overlay**. Режимы:

- **Native** — локальная программа / sidecar рисует кадры (`:8092`).
- **Browser (local)** — локальная программа; CEF на `127.0.0.1:8090` (старые сцены `mode=browser` остаются здесь).
- **Browser (remote)** — на ПК стримера нет программы; вставьте URL оверлея модератора или join code + relay.

Обычный Browser Source OBS работает и без плагина (`http://127.0.0.1:8090/obs?t=…` на ПК host).

## OBS Browser Source

1. Ширина **1920**, высота **1080**.
2. **Тот же ПК, что приложение:** URL из приложения после PIN (`/obs?t=…`), localhost.
3. **Стример только с плагином:** модератор копирует **URL оверлея** из Настройки → Connector. Mesh: `http://<ip>:8090/obs?t=…`. Свой relay: `https://relay…/o/{code}/obs`. Стример — режим плагина **Browser (remote)**.
4. Опционально: «Обновлять браузер при активации сцены».

Native и режимы плагина: [obs-omo-connector/README.md](../../obs-omo-connector/README.md). Удалённое сопряжение: [CONNECTOR.md](CONNECTOR.md).

## Холст — шпаргалка

- Колёсико: зум к курсору
- Пробел + перетаскивание или СКМ: панорама
- Ctrl+0 — вписать, Ctrl+1 — 100%
- Shift + движение: ось; Alt + движение: без snap
- ПКМ по медиа: соотношение сторон

## Удалённые моды

См. [CONNECTOR.md](CONNECTOR.md). В Настройки → Connector: Tailscale, Headscale, NetBird, ZeroTier, Radmin VPN, WireGuard, Cloudflare Tunnel и ваш WSS relay. OMO **не** включает эти клиенты. Не пробрасывайте 8090/4455 в интернет.
